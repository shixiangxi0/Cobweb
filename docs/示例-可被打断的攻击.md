# 示例：可被打断的攻击

这个例子展示双世界设计最核心的三个机制：

- **临时状态**：一个有时间限制的临时状态窗口
- **可打断**：新事件到达时，旧窗口被原子撤销
- **逻辑/表现分离**：伤害判定与动画播放完全解耦

## 场景

1. 玩家按攻击键 → 进入 2 秒前摇
2. 前摇期间按闪避键 → 攻击取消，不产生伤害
3. 前摇完成 → 造成 20 点伤害

## 分析

 1.  是否会影响未来状态，会，所以不在表现层
 2.  进一步分析，是否会被未来事件打断，会，所以不是简单的逻辑层状态
 3.  结论：需要用临时状态窗口来完成这个攻击和闪避事件

## 代码

```typescript

// ============================================
// 1. 事件定义（系统的唯一输入）
// ============================================
type Event =
  | { type: 'input:attack' }
  | { type: 'input:dodge' };

// ============================================
// 2. 逻辑层
// ============================================
const logic = {
  casting: null as string | null,

  // 规则：事件 → 状态变化
  reduce(e: Event) {
    switch (e.type) {
      case 'input:attack': {
        // 创建新的临时状态窗口，旧的自动被抢占
        const id = timelord.grant(2000, () => {
          // 窗口正常结束：事务提交
          this.casting = null;
          console.log('  [逻辑] 攻击命中，造成 20 伤害');
        }, () => {
          // 窗口被打断：事务回滚
          this.casting = null;
          console.log('  [逻辑] 攻击被打断，无伤害');
        });
        this.casting = id;
        console.log('  [逻辑] 开始攻击前摇');
        break;
      }
      case 'input:dodge': {
        if (this.casting) {
          timelord.revoke(this.casting, 'abort');
        }
        console.log('  [逻辑] 闪避');
        break;
      }
    }
  }
};

// ============================================
// 3. 临时状态管理器（逻辑层的内部机制）
// ============================================
let _timelordId = 0;

const timelord = {
  active: null as { id: string; timer: any; commit: () => void; abort: () => void } | null,

  grant(ms: number, onCommit: () => void, onAbort: () => void) {
    if (this.active) this.revoke(this.active.id, 'abort');  // 抢占旧窗口
    const id = `window_${++_timelordId}`;
    this.active = {
      id,
      commit: onCommit,
      abort: onAbort,
      timer: setTimeout(() => this.revoke(id, 'commit'), ms),
    };
    return id;
  },

  revoke(id: string, mode: 'commit' | 'abort') {
    if (!this.active || this.active.id !== id) return;
    clearTimeout(this.active.timer);
    const t = this.active;
    this.active = null;
    mode === 'commit' ? t.commit() : t.abort();
  }
};

// ============================================
// 4. 表现层（渲染组件）
// ============================================
const renderer = {
  onEvent(e: Event) {
    switch (e.type) {
      case 'input:attack':
        console.log('  [表现] 播放攻击前摇动画 ────────>');
        break;
      case 'input:dodge':
        console.log('  [表现] 播放闪避动画');
        break;
    }
  }
};

// ============================================
// 5. 事件总线
// ============================================
function emit(e: Event) {
  logic.reduce(e);
  renderer.onEvent(e);
}

// ============================================
// 6. 运行演示
// ============================================
console.log('场景：攻击 1 秒后被闪避打断\n');

emit({ type: 'input:attack' });
setTimeout(() => emit({ type: 'input:dodge' }), 1000);
```

## 运行效果

```
场景：攻击 1 秒后被闪避打断

  [逻辑] 开始攻击前摇
  [表现] 播放攻击前摇动画 ────────>
  [逻辑] 攻击被打断，无伤害
  [逻辑] 闪避
  [表现] 播放闪避动画
```

## 对应关系

| 代码 | 理论概念 |
|------|---------|
| `Event` 类型 | **逻辑事件**的输入接口 |
| `logic.reduce()` | **逻辑层**的规则推演 |
| `timelord.grant/revoke` | **临时状态**的创建与撤销 |
| `renderer.onEvent()` | **表现层** |
| `emit()` | 单向数据流：逻辑驱动表现 |
