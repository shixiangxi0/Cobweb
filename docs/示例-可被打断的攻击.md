# 示例：可被打断的攻击

这个例子展示双世界设计最核心的三个机制：

- **临时状态**：用简单字段管理有时间限制的行为
- **可打断**：新事件到达时，旧状态被干净重置
- **逻辑/表现分离**：伤害判定与动画播放完全解耦

## 场景

1. 玩家按攻击键 → 进入 2 秒前摇
2. 前摇期间按闪避键 → 攻击取消，不产生伤害
3. 前摇完成 → 造成 20 点伤害

## 代码

```typescript
// ============================================
// 1. 状态定义
// ============================================
interface State {
  player: {
    status: 'idle' | 'attacking';
    casting: null | { elapsed: number; duration: number };
  };
}

const initialState: State = {
  player: {
    status: 'idle',
    casting: null,
  },
};

// ============================================
// 2. 事件定义
// ============================================
type Event =
  | { type: 'input:attack' }
  | { type: 'input:dodge' }
  | { type: 'tick'; dt: number };

// ============================================
// 3. 逻辑层（纯函数）
// ============================================
function reduce(state: State, event: Event): State {
  const next = structuredClone(state);

  switch (event.type) {
    case 'input:attack': {
      if (next.player.casting) {
        next.player.casting = null;  // 打断旧攻击
      }
      next.player.casting = { elapsed: 0, duration: 2000 };
      next.player.status = 'attacking';
      break;
    }

    case 'input:dodge': {
      if (next.player.casting) {
        next.player.casting = null;
        next.player.status = 'idle';
      }
      break;
    }

    case 'tick': {
      const c = next.player.casting;
      if (c) {
        c.elapsed += event.dt;
        if (c.elapsed >= c.duration) {
          next.player.casting = null;  // 攻击完成
          next.player.status = 'idle';
        }
      }
      break;
    }
  }

  return next;
}

// ============================================
// 4. 表现层（只读快照）
// ============================================
const renderer = {
  last: null as State | null,

  update(curr: State) {
    const last = this.last;

    if (curr.player.status !== last?.player.status) {
      if (curr.player.status === 'attacking') {
        console.log('  [表现] 播放攻击前摇动画');
      }
      if (curr.player.status === 'idle' && last?.player.status === 'attacking') {
        const completed = last.player.casting && last.player.casting.elapsed >= 2000;
        console.log(completed ? '  [表现] 播放攻击命中特效' : '  [表现] 攻击动画中断，播放收招');
      }
    }

    this.last = structuredClone(curr);
  },
};

// ============================================
// 5. 事件总线（带日志）
// ============================================
const eventLog: Event[] = [];
let currentState = initialState;

function emit(event: Event) {
  eventLog.push(event);
  currentState = reduce(currentState, event);
  renderer.update(currentState);
}

// ============================================
// 6. 运行演示
// ============================================
console.log('=== 场景：攻击 1 秒后被闪避打断 ===\n');

emit({ type: 'input:attack' });
emit({ type: 'tick', dt: 500 });
emit({ type: 'tick', dt: 500 });
emit({ type: 'input:dodge' });

// 回放验证
console.log('\n=== 回放验证 ===\n');
let replay = initialState;
for (const e of eventLog) replay = reduce(replay, e);
console.log('回放结果:', JSON.stringify(replay.player));

// 单元测试
function test() {
  let s = initialState;
  s = reduce(s, { type: 'input:attack' });
  s = reduce(s, { type: 'tick', dt: 2000 });
  console.assert(s.player.status === 'idle' && s.player.casting === null, '攻击完成测试失败');

  s = initialState;
  s = reduce(s, { type: 'input:attack' });
  s = reduce(s, { type: 'tick', dt: 500 });
  s = reduce(s, { type: 'input:dodge' });
  console.assert(s.player.status === 'idle' && s.player.casting === null, '闪避打断测试失败');

  console.log('测试通过 ✓');
}
test();
```

```

  [表现] 播放攻击前摇动画
  [表现] 攻击动画中断，播放收招

=== 回放验证 ===

测试通过 ✓
```

## 对应关系

| 代码 | 概念 |
|------|------|
| `reduce(state, event)` | **逻辑层**：纯函数，无副作用 |
| `player.casting` | **临时状态**：普通对象，用完即删 |
| `eventLog` | **事件日志**：可回放、可追溯 |
| `renderer.update(snapshot)` | **表现层**：只读快照，diff 驱动 |
| `reduce(initialState, event)` | **单元测试**：纯函数，无需启动引擎 |
