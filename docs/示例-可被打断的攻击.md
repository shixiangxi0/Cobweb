# 示例：可被打断的攻击

这个例子展示双世界设计最核心的三个机制：

- **临时状态**：用简单状态字段管理有时间限制的行为
- **可打断**：新事件到达时，旧状态被干净重置
- **逻辑/表现分离**：伤害判定与动画播放完全解耦

## 场景

1. 玩家按攻击键 → 进入 2 秒前摇
2. 前摇期间按闪避键 → 攻击取消，不产生伤害
3. 前摇完成 → 造成 20 点伤害

## 分析

 1.  是否会影响未来状态，会，所以不在表现层
 2.  进一步分析，是否会被未来事件打断，会，所以需要用临时状态管理
 3.  结论：用 `casting` 临时状态字段 + `tick` 事件推进

## 代码

```typescript

// ============================================
// 1. 事件定义（系统的唯一输入）
// ============================================
type Event =
  | { type: 'input:attack' }
  | { type: 'input:dodge' }
  | { type: 'tick'; dt: number };  // 每帧推进时间

// ============================================
// 2. 逻辑层
// ============================================
const logic = {
  state: {
    casting: null as {
      elapsed: number;
      duration: number;
    } | null,
    hp: 100,
  },

  // 规则：事件 → 状态变化
  reduce(e: Event) {
    switch (e.type) {
      case 'input:attack':
        this.startAttack();
        break;
      case 'input:dodge':
        this.tryDodge();
        break;
      case 'tick':
        this.advance(e.dt);
        break;
    }
  },

  startAttack() {
    // 如果已经在攻击，先打断旧的
    if (this.state.casting) {
      this.state.casting = null;
      console.log('  [逻辑] 旧攻击被打断（新攻击覆盖）');
    }
    this.state.casting = { elapsed: 0, duration: 2000 };
    console.log('  [逻辑] 开始攻击前摇');
  },

  tryDodge() {
    if (this.state.casting) {
      this.state.casting = null;
      console.log('  [逻辑] 攻击被打断（闪避），无伤害');
    }
    console.log('  [逻辑] 闪避');
  },

  advance(dt: number) {
    const c = this.state.casting;
    if (!c) return;
    c.elapsed += dt;
    if (c.elapsed >= c.duration) {
      this.state.casting = null;
      console.log('  [逻辑] 攻击命中，造成 20 伤害');
    }
  },
};

// ============================================
// 3. 表现层（只读快照，不收事件）
// ============================================
const renderer = {
  lastSnapshot: null as typeof logic.state | null,

  update(snapshot: typeof logic.state) {
    const last = this.lastSnapshot;
    const curr = snapshot;

    // 开始攻击：casting 从 null 变成有值
    if (curr.casting && !last?.casting) {
      console.log('  [表现] 播放攻击前摇动画 ────────>');
    }

    // 攻击结束：casting 从有值变成 null
    if (!curr.casting && last?.casting) {
      // 通过时间判断是否自然完成
      if (last.casting.elapsed >= last.casting.duration) {
        console.log('  [表现] 播放攻击命中特效');
      } else {
        console.log('  [表现] 攻击动画中断，播放收招');
      }
    }

    this.lastSnapshot = JSON.parse(JSON.stringify(curr));
  },
};

// ============================================
// 4. 事件总线
// ============================================
function emit(e: Event) {
  logic.reduce(e);           // 逻辑层先处理
  renderer.update(logic.state);  // 表现层读取新快照
}

// ============================================
// 5. 运行演示
// ============================================
console.log('场景：攻击 1 秒后被闪避打断\n');

emit({ type: 'input:attack' });

// 模拟帧推进
setTimeout(() => emit({ type: 'tick', dt: 500 }), 500);   // 500ms
setTimeout(() => emit({ type: 'tick', dt: 500 }), 1000);  // 1000ms
setTimeout(() => emit({ type: 'input:dodge' }), 1000);     // 闪避
```

## 对应关系

| 代码 | 概念 |
|------|------|
| `Event` 类型 | **逻辑事件**的输入接口 |
| `logic.reduce()` | **逻辑层**的规则推演 |
| `logic.state.casting` | **临时状态**字段 |
| `tick` 事件 | 时间推进的确定性事件 |
| `renderer.update(snapshot)` | **表现层**读取快照 |
| `emit()` | 单向数据流：逻辑先处理，表现后读取 |


## 关键设计点

### 1. 临时状态就是普通对象

没有 `timelord`，没有回调，没有管理器。`casting` 就是一个普通对象，有 `elapsed` 和 `duration` 两个字段。

```ts
this.state.casting = { elapsed: 0, duration: 2000 };
```

打断就是直接赋值 `null`：

```ts
this.state.casting = null;  // 清理完成
```

### 2. 时间推进是事件，不是回调

```ts
{ type: 'tick', dt: 16 }  // 每帧发一次
```

逻辑层收到 tick 后推进 `elapsed`，到达阈值就结算。这是确定性的、可测试的、可回放的。

### 3. 表现层只读快照，不收事件

表现层不监听 `input:attack` 或 `input:dodge`。它只比较前后两帧的快照：

- `casting` 从 `null` → 有值 → 开始播放攻击动画
- `casting` 从有值 → `null` → 判断是自然完成还是被打断，播放对应动画

表现层的输入只有**一个**：`snapshot`。
