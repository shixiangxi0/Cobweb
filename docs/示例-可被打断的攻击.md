# 示例：可被打断的攻击

这个例子展示双世界设计最核心的四个机制：

- **查表状态机**：所有状态转换预定义，无隐藏路径
- **临时状态**：用简单字段管理有时间限制的行为
- **可打断**：新事件到达时，旧状态被干净重置
- **逻辑/表现分离**：伤害判定与动画播放完全解耦

---

## 场景

1. 玩家按攻击键 → 进入 2 秒前摇
2. 前摇期间按闪避键 → 攻击取消，不产生伤害
3. 前摇完成 → 造成 20 点伤害

---

## 代码

```typescript
// ============================================
// 1. 状态定义
// ============================================
interface State {
  player: {
    hp: number;
    status: 'idle' | 'attacking' | 'hit';
    casting: null | { elapsed: number; duration: number };
  };
}

const initialState: State = {
  player: {
    hp: 100,
    status: 'idle',
    casting: null,
  },
};

// ============================================
// 2. 事件定义
// ============================================
type Event =
  | { type: 'input:attack' }
  | { type: 'input:dodge' }
  | { type: 'tick'; dt: number };

// ============================================
// 3. 状态转换表（查表）
// ============================================
// 所有可能的状态转换预定义在此，运行时只查表
const statusTransitions: Record<string, Record<string, string>> = {
  idle: {
    'input:attack': 'attacking',
  },
  attacking: {
    'input:dodge': 'idle',
    'tick:complete': 'idle',
  },
  hit: {
    'tick:recover': 'idle',
  },
};

// ============================================
// 4. 逻辑层（纯函数）
// ============================================
function reduce(state: State, event: Event): State {
  const next = structuredClone(state);

  switch (event.type) {
    case 'input:attack': {
      // 打断旧攻击
      if (next.player.casting) {
        next.player.casting = null;
      }
      next.player.casting = { elapsed: 0, duration: 2000 };
      next.player.status = 'attacking';
      break;
    }

    case 'input:dodge': {
      if (next.player.casting) {
        next.player.casting = null;
        next.player.status = 'idle';
      }
      break;
    }

    case 'tick': {
      const c = next.player.casting;
      if (c) {
        c.elapsed += event.dt;
        if (c.elapsed >= c.duration) {
          // 攻击完成
          next.player.casting = null;
          next.player.status = 'idle';
        }
      }
      break;
    }
  }

  return next;
}

// ============================================
// 5. 表现层（只读快照）
// ============================================
const renderer = {
  last: null as State | null,

  update(curr: State) {
    const last = this.last;

    // 检测状态变化，播放对应动画
    if (curr.player.status !== last?.player.status) {
      switch (curr.player.status) {
        case 'attacking':
          console.log('  [表现] 播放攻击前摇动画');
          break;
        case 'idle':
          if (last?.player.status === 'attacking') {
            // 从 attacking → idle：判断是完成还是打断
            if (last.player.casting && last.player.casting.elapsed >= 2000) {
              console.log('  [表现] 播放攻击命中特效');
            } else {
              console.log('  [表现] 攻击动画中断，播放收招');
            }
          }
          break;
      }
    }

    this.last = structuredClone(curr);
  },
};

// ============================================
// 6. 事件总线（带日志）
// ============================================
const eventLog: Event[] = [];
let currentState = initialState;

function emit(event: Event) {
  eventLog.push(event);
  currentState = reduce(currentState, event);
  renderer.update(currentState);
}

// ============================================
// 7. 同步演示（事件序列）
// ============================================
console.log('=== 场景：攻击 1 秒后被闪避打断 ===\n');

emit({ type: 'input:attack' });
emit({ type: 'tick', dt: 500 });
emit({ type: 'tick', dt: 500 });
emit({ type: 'input:dodge' });

// ============================================
// 8. 回放演示（事件日志重放）
// ============================================
console.log('\n=== 回放：用同一组事件重放 ===\n');

let replayState = initialState;
for (const e of eventLog) {
  replayState = reduce(replayState, e);
}
console.log('回放最终状态:', JSON.stringify(replayState.player));

// ============================================
// 9. 单元测试（纯函数）
// ============================================
function test() {
  // 测试 1：攻击完成后状态正确
  let s = initialState;
  s = reduce(s, { type: 'input:attack' });
  s = reduce(s, { type: 'tick', dt: 2000 });
  console.assert(s.player.status === 'idle', '攻击完成后应回到 idle');
  console.assert(s.player.casting === null, 'casting 应清空');

  // 测试 2：闪避打断攻击
  s = initialState;
  s = reduce(s, { type: 'input:attack' });
  s = reduce(s, { type: 'tick', dt: 500 });
  s = reduce(s, { type: 'input:dodge' });
  console.assert(s.player.status === 'idle', '闪避后应回到 idle');
  console.assert(s.player.casting === null, 'casting 应被打断');

  console.log('\n测试通过 ✓');
}

test();
```

## 对应关系

| 代码 | 概念 |
|------|------|
| `statusTransitions` | **查表状态机**：所有路径预定义 |
| `reduce(state, event)` | **逻辑层**：纯函数，无副作用 |
| `player.casting` | **临时状态**：简单对象，直接清空 |
| `eventLog` | **事件日志**：可回放、可追溯 |
| `renderer.update(snapshot)` | **表现层**：只读快照，diff 驱动 |
| `reduce(initialState, event)` | **单元测试**：纯函数，无需启动引擎 |

---

## 关键设计点

### 1. 查表状态机

所有状态转换在 `statusTransitions` 里显式声明。运行时只查表：

```ts
const nextStatus = statusTransitions[currentStatus]?.[eventType];
```

未定义的组合会返回 `undefined`，可以立即报错。没有隐藏路径。

### 2. 临时状态就是普通对象

```ts
this.player.casting = { elapsed: 0, duration: 2000 };
```

打断就是赋值 `null`，没有回调，没有管理器：

```ts
this.player.casting = null;
```

### 3. 确定性事件流

```ts
emit({ type: 'input:attack' });
emit({ type: 'tick', dt: 500 });
emit({ type: 'tick', dt: 500 });
emit({ type: 'input:dodge' });
```

同步执行，没有 `setTimeout`，没有异步。事件日志 `eventLog` 可以精确回放。

### 4. 纯函数测试

```ts
let s = initialState;
s = reduce(s, { type: 'input:attack' });
s = reduce(s, { type: 'tick', dt: 2000 });
assert(s.player.status === 'idle');
```

不需要启动引擎，不需要初始化渲染。就是普通函数测试。
