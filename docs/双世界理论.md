# 双世界理论

---

## 两种因果

游戏里存在两种性质根本不同的因果。

第一种是**游戏因果**。血量扣减、获得装备、关卡推进——这些事件改变了游戏的未来，是对世界状态的永久写入。它是离散的，瞬时的，不可逆的。

第二种是**感知因果**。挥刀动画、追击移动、粒子效果——这些状态的演进不影响任何未来的游戏推演，它们服务于当下的体验，结束即消失。

这两种因果运行在不同的轴上，性质正交。双世界理论的全部，都从这个区分出发。

---

## 三层主权

基于这个区分，系统的因果权力自然分成三层：

```
世界因果树  →  终极因果主权（永久，跨场景）
局部因果    →  委托主权（随场景生灭）
表现运行时  →  感知主权（可丢弃，不持有因果事实）
```

**世界因果树**是持久层。它只记录需要跨越场景边界的因果事实，不参与局部规则运算，但对下层始终保有最终的抢占权。

**局部因果**是世界因果树向当前场景颁发的委托主权。场景内的所有状态推演都在这里发生，场景结束时，重要结论写回世界因果树，局部状态整体销毁。

**表现运行时**是渲染组件树。它读取局部因果的输出，把离散的状态变化呈现为连续体验。它没有持久因果权力，但它并不是被动的——这是理解双世界的关键。

---

## 渲染组件自治

渲染组件不是纯视觉单元，它是**前端组件自治思想在游戏中的延伸**。

一个怪物组件挂载，代表这个怪物存在于世界里。它的 `update(dt)` 里可以跑完整的行为逻辑：检测玩家距离、决策追击、执行攻击前摇。组件卸载，怪物消失。**生命周期本身就是行为的载体。**

组件内的一切——状态、动画、时间相关的行为——默认自治。追击过程中的移动轨迹、攻击动作的帧编排、进入范围的触发检测，这些都在组件内部运行，不需要请示任何上层。

只有当行为**触碰了局部因果**，才向上报事件：

```
组件内自治（不上报）        触碰局部因果（上报事件）
──────────────────────     ──────────────────────
追击移动                    命中判定
攻击动画编排                血量扣减
范围检测                    死亡
前摇后摇                    拾取触发
```

这套自治边界让渲染组件成为真正独立的单元——可以组合、嵌套、单独测试，整个组件树的复杂度可以自由拆分，而不影响局部因果层的干净程度。

---

## 时间因果主权

连续型游戏引出一个更深的问题：ACT 的连击窗口、格挡判定帧、实时物理模拟——这些在一段持续时间内连续地产生状态，它们不是单次事件触发的结果，但它们是真实的因果事实，影响未来推演。它们归属于哪里？

这需要一个新的概念来解决——**时间因果主权**。

**时间因果主权是局部因果在一段时间窗口内对局部临时状态的完整自治权**。它允许局部世界在这个窗口内连续地读写临时状态，执行帧级规则，运行物理模拟。格挡判定帧和连击窗口都是局部因果的内部状态，在时间因果主权的管辖下运行，而不应该属于渲染组件——如果把它们放进渲染组件，那打断就会引发竞争；需要分层管理，让打断，撤销等行为只是干净的局部状态重置。


时间因果主权有三个核心属性：

- **有时效**：主权存在于一个时间窗口内，窗口关闭，主权自然消亡
- **可撤销**：上层事件到达时，主权可以被立即抢占，局部状态重置
- **沙盒化**：主权范围内的状态是临时的，不能写入世界因果树

---

## 确定型结构

委托主权可以被上层随时打断。

玩家按下闪避，局部因果判断当前是否处于不可打断状态（某些硬直帧），再决定是否执行闪避规则。如果执行，局部状态重置，渲染组件收到新的状态指令。被丢弃的动画帧本来就不是因果事实，什么都不会损坏。

在声明式状态机里，打断是一次强制跳转：

```
animating ──interrupt──> idle
```

这条边显式声明在状态图里，跳转就是查一下这条边是否存在，完全确定性的。

整个系统追求的不是确定性结果，而是**确定性结构**。闪避有没有成功不确定，但所有可能的结果都被预先枚举，每个出口都有定义好的衔接。不确定的只是走哪条路，不是路本身存不存在。

---

## 黄金标准

三层结构落地，始终回到同一个问题：

**这件事是否影响未来的因果推演？**

不影响的，归渲染组件，默认自治，可丢弃。影响但只在当前场景内有效的，归局部因果，随场景生灭。影响跨场景推演的，归世界因果树，必须持久化。
